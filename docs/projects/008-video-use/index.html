00 / ONE-PAGE SUMMARY

我们现在怎样理解 video-use？

它是以语音内容为主线的代理视频剪辑工作流：识别音频，得到“说了什么、何时说”；代理结合剪辑目标生成 EDL；FFmpeg 据此同步裁剪音画、制作字幕并导出成片。它擅长口播、访谈、教程和产品讲解，可补上我们从素材制作到发布之间的粗剪环节。画面按需抽样核查，并非全片逐帧理解。

打开高清总览图 ↗
核心判断Scribe 类似 Whisper，负责识别和原始时间戳；真正的剪辑决定由代理做，实际裁剪由脚本做。
隐藏问题：时间对齐 ≠ 画面连续。剪掉一句话后，人物姿态、手势或屏幕画面可能突然跳变；字幕与切点也会受识别错误影响。必须预览切点，必要时调整 EDL、插入补充画面或人工精剪。
MODEL / WHERE IT RUNS

模型在哪里运行？

video-use 本身不附带通用大模型权重，也不要求部署一台专属的 video-use 大模型服务器。它借用你选用的代码代理做判断，另用专门的语音服务做转写。

剪辑判断 / 外部代理

大模型由代理提供

Claude Code、Codex 等代理阅读转写、提出策略并写 EDL。模型实际在云端还是本地，取决于所用代理；仓库没有内置或指定一个本地 LLM。

默认调用 ElevenLabs

现成的转写脚本把提取的音频上传到 ElevenLabs Scribe，取回逐词时间戳。这是专门的语音识别服务，不是负责剪辑决策的通用大模型。

01 / HOW IT WORKS

视频不必逐帧读完。

它以语音文本作为主要索引；遇到拿不准的停顿、重录或切点，再查看局部画面与波形。编辑决定由代理形成，确定性的音视频处理交给脚本。

01
01 / INPUT

导入素材

盘点视频、时长与音轨，明确内容目标。

02 / SPEECH

逐词转写

提取音频，调用 Scribe 取得词级时间戳。

03 / PACK

压缩阅读

按停顿和说话人合并成短句表。

04 / DECIDE

代理写 EDL

按确认的策略，选择片段、顺序与切点。

05 / RENDER

合成成片

FFmpeg 切片、拼接、调色、加字幕与叠加层。

06 / REVIEW

检查修改

核对切点附近的画面和波形，再返工。

这里的“看视频”是按需抽帧。仓库的主设计是文字驱动剪辑，尤其适合有讲话的素材。查看上游工作流程 ↗

03 / UNDER THE HOOD

两份关键数据，把判断和执行接起来。

短句表帮助代理理解素材；EDL 让剪辑决定成为可重复执行的结构化输入。

03
01 / takes_packed.md

用时间戳阅读内容

逐词结果按至少 0.5 秒停顿或说话人变化分组。代理先比较要讲什么，再去核查少量画面。

## TAKE_03
[02.52–05.36] S0 先看用户遇到了什么问题。
[06.08–08.74] S0 然后展示我们如何解决。
02 / edl.json

把选择写成剪辑表

每个区间注明源视频、起止秒数和叙事作用；渲染器据此切片、拼接和生成字幕。

{
  "source": "take_03",
  "start": 2.52,
  "end": 8.74,
  "beat": "问题 → 解决方案"
}
模型没有逐帧看完整视频。视觉信息来自指定区间的抽帧与波形；因此它在口播内容剪辑上更有优势，动作或音乐主导的视频仍需额外索引能力。
04 / WHERE IT FITS

哪些素材，值得交给它？

判断的核心是：视频的信息主要由讲话承载，还是由画面动作、节奏和镜头语言承载。

04
适配度高

产品讲解与教程

按讲述结构保留关键句，删掉重说与等待，配合字幕和演示图形。

适配度高

口播与访谈

跨多个 take 选择更清楚的表达，保留问答和情绪重点。

需要补充能力

音乐与少对白蒙太奇

音频转写提供的信息有限；选镜头还需要动作、画面语义与节拍分析。

06 / EXTENSION ROADMAP

下一步可扩展什么？

以下是基于现有实现提出的建设方向，不计入仓库已完成能力。

06
P0 / 先解决

中文与可靠缓存

  • 中文断句、标点、字体与专有名词校对。
  • 用源文件指纹使转写缓存正确失效。
  • 在 Windows 上验证路径与字幕滤镜。
P1 / 便于采用

可控与可审核

  • 增加可替换或本地运行的转写服务。
  • 做可视化 EDL 审稿和逐切点修改。
  • 建立黑帧、静音、字幕越界等质量门禁。
P2 / 拓宽场景

理解更多画面

  • 加入镜头切换、OCR、动作与节拍索引。
  • 导出到专业剪辑软件继续精剪。
  • 沉淀品牌模板与多比例批量出片。
BEFORE YOU ADOPT

试用前，记住这些边界。

文档区分源码已实现、Skill 指导和未来扩展；发布级视频仍需视听复核。

切点可能让画面跳变

FFmpeg 能按同一时间戳裁切音频和视频，但相邻片段的人物姿态、镜头和屏幕内容可能不连贯。抽帧与波形只辅助检查，成片仍需逐切点预览和人工修正。查看切点检查流程 ↗

音频上传到第三方

默认转写通过 ElevenLabs Scribe API 完成，涉及网络、API 成本和素材保密要求。查看代码 ↗

同名素材可能复用旧转写

当前缓存只检查输出 JSON 是否存在，源视频变化后需主动处理。查看代码 ↗

中文与 Windows 尚待验证

默认字幕分组偏英文；安装说明主要列出 macOS/Linux 命令。本研究尚未在本机跑通。查看安装说明 ↗
