02 / WHAT IT NEEDS

运行它，需要哪些资源？

先准备完整书库和一台运行设备；封面提取、格式转换、设备同步与外部登录按需求增加。

基础资源 · 必备

书库 + 服务 + 备份

01

Calibre 书库

metadata.db 保存书目；书库目录同时保留电子书文件。只有散落文件时，先建立有效书库。

02

运行设备

电脑、NAS 或服务器运行 Calibre-Web。官方要求 Python 3.7 或更新版本；浏览器负责访问界面。

03

数据与访问

备份整个 Calibre 书库和 Calibre-Web 的 app.db；跨设备访问还需要网络地址，对外使用应配置 HTTPS。

连接

设备与邮件

高级搜索：现有代码按标题、作者、标签、简介等书目字段查询；正文检索和语义问答需要独立提取与索引流程。

04 / WHERE IT FITS

哪些场景值得用？

这些场景使用的都是已经具备的书库、阅读和分发能力。

01

个人藏书

把长期积累的 EPUB、PDF 分类编目，在电脑与手机上快速找到、打开或下载。

02

家庭或团队共读

用账号、权限和书架组织阅读资料，让成员看到适合自己的内容。

03

阅读器供书

通过 OPDS 目录找书，或在官方兼容范围内配置 Kobo 同步。

04

内容创作资料库

按主题和来源管理参考书，供选题、查证、写作时回到原始资料。
