012 / VIDEO PRODUCTION ENGINE

把一个主题
变成一条短视频。

HOW THE PICTURE MOVES

画面是怎样动起来的？

现成视频

图库或自有实拍本身已有连续画面；程序裁切、调速、适配画幅和拼接。

静态图片

自有照片或 AI 生图提供一张画面；程序将其慢慢放大，渲染成视频片段。

AI 视频

按关键词向外部视频模型请求动态短片段，再交给同一条剪辑流程。

这里没有固定的“先生成一张主画面，再补全所有镜头”机制。淡入、滑入、缩放等转场也是程序效果。查看画面处理源码 ↗

关键理解

预先编写的 Python 程序负责调度：大模型生成文案与画面线索，素材可检索或由视频模型生成片段，TTS 生成声音，MoviePy / FFmpeg 将画面、字幕和音轨合成为最终视频。

04 / WHERE IT FITS

适合哪些内容？

适合作为结构清晰、可复用素材、允许人工审片的短视频生产工具。

01 / KNOWLEDGE

知识与科普

把一个主题解释成几十秒旁白，用相关画面和字幕辅助理解。

咖啡冲煮 · 科学常识 · 阅读笔记
02 / BRAND

品牌内容初稿

结合品牌自己的素材和话术，快速形成多版可讨论的短视频。

门店介绍 · 活动预热 · 产品亮点
03 / SCALE

系列内容批量制作

统一画幅、音色和字幕风格，批量完成主题相近的视频任务。

每日知识 · 课程片段 · 账号栏目
需要人工把关的情况

事实敏感内容、严格品牌画面、商品功效承诺、素材授权或平台发布要求。自动生成可以缩短制作过程，最终交付仍要审核。

05 / PRODUCT OPPORTUNITY

如果要做自己的产品，
可以从这里起步。

对你来说，直接价值是复用已有生成流程，尽快验证一个具体人群的需求。产品差异要建立在他们真正关心的交付环节。

A / REUSE

复用生成引擎

保留脚本、素材、配音、字幕、合成和 API 等基础能力，先做出可交付的第一版。

B / DIFFERENTIATE

做垂直工作台

选择一个用户群，提供专属模板、自有素材库、逐镜头编辑和审核，让结果更稳定、可控。

C / OPERATE

补齐运营层

增加账号与团队隔离、任务队列、成本和用量统计、文件存储、失败重试与监控。

EXTENSION / LOGIC-DRIVEN VISUALS

想讲清物理逻辑，需要增加图形动画层。

当前工具可以为“自由落体”写解说、寻找相关视频、生成配音和成片；它的主流程不会把公式自动转成受力箭头、运动轨迹和严格按参数变化的曲线。若把这些画面由额外的计算与图形渲染模块做出来，再作为本地素材交给现有合成链，就能形成更适合教学的产品。

概念 / 公式→参数与规则→图形动画片段→配音 / 字幕 / 成片
建议的第一轮验证选 1 类用户 · 收集 20 个真实题目 · 量化 4 个结果

记录成功出片率、每条成本、人工修改时间，以及用户是否愿意采用成片。这些数据能帮助确定下一步先改质量、编辑，还是交付。

项目采用 MIT 许可；商业使用仍需分别核对素材、音乐和外部模型服务的条款。仓库提示了内置音乐的权利问题。
