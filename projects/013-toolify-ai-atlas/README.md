## 研究摘要

Toolify 是 AI 产品发现目录，提供按类别浏览、最新产品、收藏量、使用量、榜单等入口。其首页在本次查阅时列出 **22 个大类**，具体产品还带有更细的能力标签，例如 AI Chatbot、AI Transcription、AI App Builder、AI Workflow、AI OCR 和 AI 3D Model Generator。目录的分类是产品发现入口，不能直接当作互斥的技术分类或产品质量排名。

网页完整列出本次查阅时 Toolify 分类目录可见的 22 个大类、459 个细分类，再以六个便于学习的方向组织代表产品；另设 3D 模型专题。类别目录按快照逐项收录，产品案例是精选导读。

1. 对话与知识工作：问答、写作、办公、学习与翻译。
2. 多媒体创作：图像、视频、声音、音乐、设计。
3. 开发与流程：编程、应用构建、企业工作流。
4. 增长与商业：营销、社交媒体、商业探索。
5. 研究与识别：资料研究、数据分析、图像识别、内容检测。
6. 生活与专业场景：日常、健康、法律财务、空间设计，以及跨类工具。

六个方向是**本站的学习视角**，不是 Toolify 官方的上级分类。一个产品可以横跨多个方向，例如聊天助手可能同时支持写作、研究、图片理解和工作流。

## 怎么理解 AI 产品能力

先看任务，再看产品名称。每项能力都可以拆成四个问题：

| 问题 | 要观察什么 | 例子 |
| --- | --- | --- |
| 输入 | 用户给工具什么材料 | 文字、录音、图片、视频、文档、表格、业务数据 |
| 处理 | AI 实际做了什么 | 生成、识别、检索、抽取、分类、预测、调用工具 |
| 输出 | 产物能否直接进入下一步 | 答案、脚本、图片、字幕、代码、结构化数据、已执行操作 |
| 验证 | 如何判断它可用 | 正确率、可编辑性、版权与授权、延迟、成本、人工复核 |

网页提供 459 个细分类的完整目录、搜索和大类筛选；代表产品区每个首页大类展示两款案例；3D 模型专题与覆盖检查各列出七款补充产品，并链接到 Toolify 细分类及产品页。产品案例未逐一测试，也不构成推荐或质量评测。价格、免费额度、排名与产品收录量变化很快，因此网页不复写这些数据。

## 值得借鉴的做法

1. **先按任务找工具：** “录音转字幕”比“找一个强大的 AI”更容易定位到语音转写类产品。
2. **区分底层能力与产品包装：** 同一种生成或识别能力可以被包装成客服、办公、营销、教育等不同应用。
3. **保留来源并标注判断：** Toolify 的目录信息与本站的学习归纳分开呈现。
