# 001 · Retrieval-based-Voice-Conversion-WebUI

> RVC 将已有的讲话或歌声转换成目标音色。它把少量目标声音微调、特征检索和波形合成接成了可通过网页、命令行与实时界面使用的完整流程。

## 研究摘要

**能力：** 把已有讲话或歌声转换成目标声线，支持离线批量转换、实时变声和目标声线训练，并提供人声分离等辅助功能。

**实现原理：** HuBERT 提取发音特征，RMVPE 等方法估计音高，RVC 目标声线模型生成新波形；可选特征检索减轻原声残留，多个模型通过同一套程序协作。

**对我的意义：** 可作为自建软件的换声模块，也可借鉴预训练模型、目标微调与检索协作的方法。当前以理解为主，无需立即安装；实际音质、相似度和设备延迟需日后验证。

## 能力与边界

| 能力 | 输入 | 输出或作用 | 边界 |
| --- | --- | --- | --- |
| 目标音色训练 | 获得授权的清晰目标声音 | 可供转换使用的模型与特征索引 | 录音质量比极短时长更关键 |
| 离线语音和歌声转换 | 已有语音或歌声、目标模型 | 目标音色音频；可调音高、批量处理 | 原始发音、演唱和噪声会影响效果 |
| 实时变声 | 麦克风输入、音频设备、目标模型 | 持续转换的声音 | 延迟取决于算力、驱动和分块设置 |
| 人声处理 | 带伴奏或混响的音频 | 分离人声、伴奏或去混响，便于后续转换 | 分离质量影响最终结果 |
| 多音色模型 | 多位说话人的训练素材 | 在同一模型内选择不同说话人 | 各说话人的检索索引分别建立 |

### 它在工作流中的位置

- **内容制作：** 录制台词 → RVC 转换音色 → 人工试听与修音。
- **音乐制作：** 分离人声 → RVC 转换歌声音色 → 与伴奏重新混合。
- **实时互动：** 麦克风 → 实时 RVC → 音频输出；需要验证设备和驱动延迟。
- **文字驱动配音：** 文字 → 文字转语音（TTS）→ RVC 转换音色。RVC 只承担后半段。

## 理解换声所需的声音基础

### 先有声波，再有数字录音

空气中的声音是传播的压力变化。声源振动使周围空气交替压缩、变稀，麦克风把这种变化转换为电信号，采样后得到一串数字。按时间画出这些数值，就是数字波形。发音内容、音高和音色共同体现在波形中，没有独立的“内容轨”和“音色轨”。

### 音高、音量与音色

| 概念 | 感受 | 主要相关因素 | 例子 |
| --- | --- | --- | --- |
| 音高 | 高还是低 | 对有明确音高的声音，主要与基频有关 | 同一个人由低音唱到高音 |
| 音量 / 响度 | 响还是轻 | 振幅、频率、持续时间与听音条件等 | 同一个音大声或小声发出 |
| 音色 | 声音的质感 | 各频率成分比例、起音衰减、噪声与变化方式等 | 两人唱同一个音，仍听得出声线不同 |

基频为 220 Hz 的周期声音，每秒重复 220 次，还可能带有 440、660 Hz 等谐波。相同基频下改变各谐波的比例，可以改变音色；音色还有随时间变化的包络和噪声等因素。因此，仅改变音高不能完整模拟另一个人的声音。

网页提供“只改音高、只改振幅、只改泛音比例”三组 A/B 合成音。图和音频来自同一套信号定义，波形使用相同刻度。音色对比保持基频和数字 RMS 相同，但相同数字 RMS 不代表主观响度严格相同。这些是声音基础教学样例，不是 RVC 推理结果。

### 人声如何产生，为什么难以直接拆分

发有声的“啊”时，肺部气流驱动声带振动；声音经过咽喉、口腔等声道，不同频率被不同程度地增强或减弱。共鸣形成的频谱突出区域称为共振峰；舌位和嘴形变化也参与区分元音。因此，声道同时影响发音内容和个人音色。清辅音等还会包含气流噪声，不一定有稳定基频。

### 由此理解 RVC 的任务

换声需要从来源波形估计发音与可选音高，结合目标录音训练出的模型，生成具有目标声线特征的新波形。它尽量保留原句和时间节奏，并重建目标音色对应的声学细节；这种内容与音色的分离是近似的，所以仍可能失真或残留来源音色。

基础资料：[OpenStax 声波](https://openstax.org/books/university-physics-volume-1/pages/17-1-sound-waves)、[OpenStax 音高、响度与音色](https://openstax.org/books/university-physics-volume-1/pages/17-3-sound-intensity)、[NIDCD 人声形成](https://www.nidcd.nih.gov/health/taking-care-your-voice)、[UNSW 声源、声道与发音](https://www.unsw.edu.au/news/2017/01/explainer--why-the-human-voice-is-so-versatile)、[MDN 数字音频](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer)。

## 实现原理

RVC 的关键是**把来源声音中的发音信息、音高变化与目标音色分开处理，再合成新波形**。这种分离是近似的：HuBERT 特征仍可能带有来源音色，因此检索索引用于减轻“原声线残留”。

### 训练目标声音

1. **准备样本：** 将目标人物的清晰录音切成短片段并统一采样率，保留片段波形作为模型需要学习的声音结果。
2. **提取条件：** 用 HuBERT/ContentVec 提取随时间变化的发音特征；带 F0 的配置再用音高算法提取基频 F0。发音特征不是转写后的文字，F0 记录有声部分的高低起伏。
3. **微调生成模型：** 从预训练权重继续训练基于 VITS 的生成模型，让它学习如何根据发音特征、可选的 F0 和说话人信息，生成该目标声线的音频。
4. **建立检索索引：** 将目标录音的特征向量放入 FAISS 近邻索引。多人模型会为不同说话人分别建索引。

训练后主要使用两种产物：模型文件 .pth 学到目标音色的合成方式；索引文件 .index 提供可选的目标特征检索辅助。索引是特征库，不是文字知识库，也不直接存放供拼接的语音片段。

### 转换一段来源声音

1. 读入来源录音或麦克风声音；长录音分段处理。
2. HuBERT 将来源声音编码为一串按时间排列的发音特征，因此原来的词句、停顿与节奏构成输出的基础。
3. 带 F0 的模型用 RMVPE 等算法估计来源声音的 F0。需要变调时，对这条音高轨迹升降半音。
4. 启用索引时，到目标声音的 FAISS 索引中查找相近特征。当前离线代码取 8 个近邻、按距离加权，再按索引比例与来源特征混合；可在无声辅音等部分保留更多来源特征，以减少失真。
5. 生成模型接收混合特征、F0 和目标说话人信息，合成新的音频波形；最后衔接分段并可调整音量与输出采样率。

所以它**不只是对原录音调高或调低音调**：原话主要来自来源录音，音色主要来自训练好的目标模型与目标特征索引。原始发音、训练素材和参数设置都会影响最终清晰度与相似度。

项目也支持不使用 F0 的模型；索引比例设为 0 时可跳过检索。上面描述的是常见的带 F0、启用索引的换声流程。

### 实时变声

实时界面把麦克风输入按小块送进转换流程，同时保留前后片段的上下文。输出端使用 SOLA 对齐及交叉渐变衔接相邻音频块，减轻接缝；这也说明实时延迟会受到分块大小、设备和驱动的影响。

## 值得借鉴的做法

1. **预训练模型 + 少量目标数据：** 减少从零训练的成本，使个人声音定制可以从较小的数据集开始。
2. **检索纠偏：** 从目标声音特征中查找相近特征，减轻来源音色残留，并保留可调的混合比例。
3. **完整创作链：** 将人声分离、训练、离线推理和实时转换组织在同一项目中，减少从素材到结果的流程断点。
4. **网页与命令行并存：** 网页方便人工试验，命令行的批量推理与多说话人支持有利于接入自动化流程。

## 结论与后续

- **已确认：** RVC 适合作为“已有语音 → 目标音色”的专门环节，具备离线和实时两种使用方式。
- **仍需验证：** 在自己的录音、设备和驱动上，转换的清晰度、目标音色相似度和实时延迟能否满足实际需求。
- **可用于自己的项目：** 授权音色的内容制作、角色声音实验，以及接在 TTS 后面的音色统一环节。
- **使用前提：** 代码采用 MIT 许可；目标人物声音、训练录音和歌曲素材的使用许可需要分别确认。


## 讨论后的理解总结

1. **能力定位：** RVC 输入已有讲话或歌声，主要改变声音呈现的说话人特征，尽量保留发音内容、时间结构与所需音高变化。
2. **声音基础：** 振幅、基频、谐波比例、噪声与时间变化共同塑造听感。内容、音高和音色交织在波形中，没有可直接抽换的独立“音色轨”。
3. **实现过程：** HuBERT 等模型提取发音特征，RMVPE 等方法估计音高，RVC 目标生成模型重建新波形。内容与音色的分离是近似的，效果仍需试听。
4. **核心资源：** 目标声线 .pth 是生成模型权重；RVC 网络代码与 PyTorch 加载并执行它。可选 .index 是特征数据，不是生成模型。
5. **部署与环境：** 本地或服务器描述运行位置。模型权重、网络代码、运行框架、计算设备各司其职；多种模型通常共用一套环境。
6. **安装与使用：** 常规换声已有模型调用流程；准备指定基础模型和兼容的目标声线文件即可使用。目标声线可获取现成模型或自行训练，训练和人声分离需要额外资源。
7. **对当前探索的意义：** 可以把 RVC 作为自建软件的换声候选。当前以理解能力和原理为目标，无需立即安装；未来要判断实际相似度、清晰度、实时延迟和设备性能，再开展小规模验证。

以上“是否安装”是针对当前探索目标的判断，并不代表已经验证实际效果。本项目尚未部署 RVC 或验证本机转换性能。
