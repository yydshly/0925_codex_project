# 使用价值、试点与扩展方向

## 适用价值

| 你的目标 | 可获得的价值 | 仍需投入 |
| --- | --- | --- |
| 经常制作口播、访谈、课程或产品讲解 | 快速从多条素材中挑内容，自动完成常规切片、字幕、基础调色和导出 | 给出剪辑方向、核对错词、审看节奏与最终听感 |
| 为产品做演示或发布片 | 用 EDL 保留可追溯的剪辑决定，可按讲述制作字幕和图形叠加 | 设计叙事、品牌视觉、动画内容和发布级审稿 |
| 研究或开发 AI 剪辑产品 | 复用“结构化素材 → 代理决策 → 可执行 EDL → 渲染核验”的架构 | 工程化、可靠性、界面、评价体系与运营成本 |
| 主要剪辑音乐、运动或无对白素材 | 可借用渲染器和 EDL 格式 | 自建镜头理解、动作/节拍分析与选镜逻辑 |

在不知道你的视频类型、频率与现有制作流程时，不能可靠估算节省多少时间。**值得先做一次真实试点**，再决定是否安装为日常 Skill 或二次开发。

## 建议的最小试点

选一组真实会发布的素材，包含 3–5 条重录片段，并保留一条人工剪辑对照。记录：

1. 从导入到初版的用时，以及人工修改用时。
2. 转写错词、错说话人和错误切点的数量。
3. 字幕是否可读，中文标点、断行和专有名词是否正确。
4. 画面跳变、音频爆音、对白/音乐音量与整体叙事是否可接受。
5. API 调用成本、上传限制和本机渲染时间。

**通过条件由你的发布标准决定。** 如果初版节省的时间被大量修订抵消，应先扩展质量控制，再考虑批量生产。

## 扩展优先级

| 优先级 | 方向 | 具体工作 | 解决的问题 |
| --- | --- | --- | --- |
| P0 | 中文字幕与术语 | 中文标点/断句、每行字数、字体检查、术语表、人名校对 | 当前默认字幕分组和大写样式偏英文 |
| P0 | 缓存与素材版本 | 用文件大小、修改时间或内容哈希给转写做失效判断；保留源文件指纹 | 同名素材替换后可能复用旧转写 |
| P1 | 可替换 ASR | 抽象转写接口，增加本地模型或其他云服务，并统一词级结果格式 | 隐私、成本、语种和服务依赖 |
| P1 | 可审阅 EDL | 做可视化时间线，展示保留/舍弃区间、字幕和切点，允许逐条修改 | 纯 JSON 和对话难以快速审稿；完整项目时间线尚未实现 |
| P1 | 自动质量门禁 | 检查字幕越界、黑帧、静音/峰值异常、时长偏差和素材缺失；保留人工视听复核 | Skill 自检目前主要依赖代理操作 |
| P2 | 画面语义索引 | 镜头边界、OCR、人物/动作、景别及屏幕事件检测，与转写共同供代理检索 | 少对白素材难以靠文字做选镜 |
| P2 | 剪辑工具交接 | 导出到常用 NLE 的可编辑项目格式，保留素材链接与切点 | 团队需要在专业软件中继续精剪 |
| P2 | 品牌化批量生产 | 品牌字体/色彩、字幕样式、片头片尾和多比例输出预设 | 系列视频的稳定性和重复制作成本 |

## 本机采用提醒

当前工作环境是 Windows。上游安装说明主要给出 macOS/Linux 命令；进入试点时，应首先验证 FFmpeg/FFprobe、Python 依赖、中文字体、含空格或盘符的路径，以及字幕滤镜是否在本机正确工作。这里尚未进行安装或素材测试。
